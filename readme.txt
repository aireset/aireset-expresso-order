== Description ==

O Aireset Expresso Order e um plugin comercial privado da Aireset. O pacote distribuido depende de licenca valida e nao e software sob GPL.

Titularidade: Felipe Almeman + Aireset.

== Installation ==

1. Envie a pasta do plugin para `/wp-content/plugins/`.
2. Ative o plugin no painel do WordPress.
3. Ative a licenca no fluxo oficial do produto.
4. Acesse `Aireset > Pedido Expresso`.
